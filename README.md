# 352flix — sürümler

Bu depo yalnız 352flix'in Windows kurulum dosyalarını barındırır; kaynak kod burada değildir.
Dosyalar [Releases](../../releases) sayfasında.

- **Kurulum (önerilen):** `352flix-Setup-<sürüm>.exe`. Kurulan uygulama yeni sürümleri kendisi
  bulur: *Ayarlar → 352flix → Güncellemeleri denetle → İndir → Yeniden başlat ve kur*.
  Kütüphane ve izleme geçmişi korunur.
- **Taşınabilir:** `352flix-<sürüm>.exe`. Kurulum gerektirmez ama kendini güncelleyemez;
  yeni sürümü buradan indir.

0.4.8 ya da daha eski bir sürüm kuruluysa 0.5.0'ı bir kez buradan indirip kur; sonraki sürümler
uygulamanın içinden gelir.
